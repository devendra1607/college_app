# College Admin Panel UI

Modern, clean and fully responsive college administration frontend built with **HTML + CSS + Bootstrap 5**.

## Pages
- `index.html` – Login page
- `pages/dashboard.html` – Dashboard with charts and notification slide-out panel
- `pages/students.html` – Student management table with modal
- `pages/faculty.html` – Faculty cards
- `pages/courses.html` – Course grid with actions
- `pages/attendance.html` – Attendance calendar + marking table
- `pages/fees.html` – Fees/payments and invoice preview
- `pages/reports.html` – Reports & analytics
- `pages/settings.html` – Profile, permissions, theme switch

## Design System
- Font stack: Inter / Poppins
- Glassmorphism cards and soft shadows
- Indigo/blue primary palette with neutral grays
- Reusable utility styles in `assets/css/styles.css`
- Shared interactions in `assets/js/app.js` (dark mode, mobile sidebar, notifications, charts)

## Run locally
Open `index.html` in your browser.
